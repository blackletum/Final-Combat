# FinalCombat Local Release

Repo based on the files from here:

https://github.com/blackletum/FinalCombat

but without any of the large 7Z files or LFS nonsense causing issues.

However, you will have to go into the /_pde/ folder before launching anything. Extract the 7Z file to the same folder and when it reassembles the PDE file, copy/paste that into your /game/ folder. Afterwards you can delete the entire /_pde/ folder as it will no longer be necessary. 

I *think* all the necessary files are here, but I'm honestly not sure.

I'll fix in the future if I find that to be the case. 

Check ORIGINAL_README.md for more information.
